# Proyecto Liga
## Descripción

Este proyecto es una aplicación JavaFX para gestionar información
relacionada con jugadores de una liga de fútbol.

La aplicación permite introducir y gestionar diferentes datos de
los jugadores, como:

- NIF
- Nombre
- Apellidos
- Fecha de nacimiento
- Club
- Sueldo
- Número del jugador
- Posición
- Goles
- Asistencias
- Nacionalidad

El proyecto utiliza Java y JavaFX para crear la interfaz gráfica.

## Requisitos

Para ejecutar el proyecto es necesario tener instalado:

- Java JDK 17 o superior.
- JavaFX.
- Git.
- Un IDE compatible con Java, como IntelliJ IDEA o Eclipse.
